# NotchCanvas updates

Official signed downloads and update feed for NotchCanvas for Mac.

Download the latest DMG from Releases. Open it, drag NotchCanvas into Applications,
and replace the previous copy. Existing pre-updater installations need this one
manual replacement. After that, Settings → General → Software Update checks for
updates. Automatic checks run daily; installation requires your approval by default.

Requires macOS 14.6 or later, with Apple Silicon or Intel. Liquid Glass requires
macOS 26. The Mac App Store edition receives updates through the App Store.

This repository contains release files and the public update feed only. No source
code, signing keys, credentials or user data belong here. Contact: anubhav.bora08@gmail.com.
